# LivingTown roadmap

## Working now

- Fabric 1.21.11 project scaffold.
- Java 21 build configuration.
- Automated GitHub Actions build and downloadable JAR artifact.

## Next milestones

1. **NPC foundation:** register a persistent humanoid NPC entity, spawn/list/remove commands, and a stable player-style renderer.
2. **Schedules:** editable per-NPC JSON routines with named destinations and time-of-day actions.
3. **Town navigation:** reliable walking between homes, school, shops and workplaces; avoid dangerous drops and blocked paths.
4. **Activities:** classroom attendance, sitting, chatting, working and idle behaviours.
5. **Persistence and polish:** saved relationships, memories, simple in-game help and configuration validation.

A milestone moves to **Working now** only after it builds and is tested in Minecraft 1.21.11. Features in the roadmap are not yet implemented.
